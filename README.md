
# Day-3-Automatrix

## Day 3: ESP32 Potentiometer Reading

This project reads an analog value from a potentiometer connected to GPIO 34 of an ESP32 and displays the reading on the Serial Monitor every 500 milliseconds.


## Wokwi Simulation

Run the Wokwi Simulation
(https://wokwi.com/projects/476560263759650817)

## How to Run

1. Open the Wokwi simulation link.
2. Start the simulation.
3. Open the Serial Monitor.
4. Rotate the potentiometer and observe the changing values.
